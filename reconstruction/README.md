# Reconstruction Module

Contains all 3D reconstruction pipelines and engines used in PowerTwinAI.

## Architecture Overview

```text
                 INPUT IMAGES
                      |
          +-----------+-----------+
          |                       |
          v                       v
    COLMAP PIPELINE          VGGT PIPELINE
          |                       |
   Existing ML model          VGGT-1B
          |                       |
     SIFT/COLMAP           Depth/Point Maps
          |                       |
          v                       v
     COLMAP MODEL            VGGT POINT CLOUD
          |                       |
          +-----------+-----------+
                      |
                  COMPARISON
                      |
              Runtime / Points /
              Coverage / Quality
```

---

## 1. Existing COLMAP Pipeline

- **Approach**: Classical Structure-from-Motion (SfM) + Multi-View Stereo (MVS).
- **Matching Layer**: Intelligent ML-ranked image-pair selection to prune unnecessary all-to-all pairs.
- **Pose Estimation & Triangulation**: Incremental SfM using SIFT features, RANSAC geometric verification, and global/local bundle adjustment.
- **Dense Reconstruction & Meshing**: PatchMatch Stereo depth estimation, multi-view stereo fusion, statistical outlier filtering, and Poisson surface reconstruction.
- **Outputs**: Stored under `outputs/sparse/`, `outputs/dense/`, and `outputs/mesh/`.

---

## 2. New VGGT Pipeline

- **Approach**: Deep feed-forward geometry prediction via Meta Research's **Visual Geometry Grounded Transformer** (`facebook/VGGT-1B`, CVPR Best Paper).
- **Core Mechanism**: In a single feed-forward transformer pass across views, VGGT predicts:
  - 6-DOF camera extrinsics and focal length intrinsics
  - Metric dense depth maps and depth confidences
  - Direct 3D point maps
- **3D Point Cloud**: Generated by unprojecting dense depth maps into world coordinates using predicted camera parameters, prunes low-confidence points, and applies statistical outlier filtering.
- **Outputs**: Stored under `outputs/vggt/` (`point_cloud.ply`, `cameras/`, `depth/`, `point_maps/`, `metadata.json`, and optional COLMAP format export).

---

## 3. Why VGGT Was Added

1. **Benchmark Alternative**: Provides a direct, modern feed-forward 3D reconstruction benchmark against classic iterative incremental SfM.
2. **Speed & Efficiency**: Reconstructs dense geometry in seconds per batch, bypassing CPU-intensive exhaustive SIFT matching.
3. **Weak Texture Resilience**: Transformers utilize learned priors to estimate depth across low-texture and reflective surfaces where classical keypoint matching struggles.
4. **Research Value**: Enables objective comparison of coverage, point density, and runtime between geometric vs learned reconstruction methods.

---

## 4. How to Run VGGT

1. Launch the Streamlit application:
   ```bash
   streamlit run reconstruction/v3_current/app.py
   ```
2. Upload images or select an existing dataset folder.
3. Under **3D Reconstruction Methods**, select **VGGT Reconstruction**.
4. Adjust parameters if desired (e.g. Max Sequence Frames, Confidence Filter Cutoff).
5. Click **Run VGGT Reconstruction**.
6. Switch to **Compare Results** to view side-by-side metrics and 3D overlays.

---

## 5. Hardware Acceleration & Dependencies

- **CUDA GPU**: Automatically detected. When available, uses GPU with `bfloat16` (Ampere+) or `float16`.
- **CPU Fallback**: Graceful fallback to CPU using `float32` if CUDA is unavailable.
- **Required Dependencies**:
  ```bash
  pip install torch torchvision huggingface_hub einops safetensors open3d plotly pillow numpy
  ```

---

## 6. How COLMAP and VGGT Are Compared

The **Compare Results** dashboard provides objective quantitative and visual comparisons:
- **Runtime (sec)**: Total end-to-end processing duration.
- **3D Points**: Cleaned point count reconstructed by each engine.
- **Registered Views**: Total number of successfully registered camera frames.
- **Point Cloud Coverage**: 3D bounding box volume ($m^3$) enclosing the core reconstructed scene.
- **Point Density**: Spatial density ($pts/m^3$).
- **Dual Visualizer**: Side-by-side and unified 3D overlay (COLMAP in Cyan, VGGT in Magenta).

*Note: All comparisons strictly report empirical reconstruction statistics without asserting unsubstantiated accuracy claims in the absence of ground-truth LiDAR.*
